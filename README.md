# ExManga Harvester Studio v1.9 (Manifest V3)

Расширение для браузеров на базе Chromium (Google Chrome, Brave, Edge, Vivaldi, Яндекс.Браузер) для автоматического пакетного скачивания манги и галерей с **ExHentai** (`exhentai.org`) и **E-Hentai** (`e-hentai.org`) напрямую в одноимённую папку на диске или в готовый архив `.CBZ` / `.ZIP`.

> **Краткое описание для поля About на GitHub:**
> `Manifest V3 Chrome extension for batch downloading galleries from ExHentai & E-Hentai into named folders (with duplicate detection, Smart Resume & no "Save As" popups) or single .CBZ / .ZIP archives with ComicInfo.xml, partial recovery, and automatic H@H mirror fallback.`

## Что нового в версии 1.9

* **Автоопределение уже скачанной манги (защита от дубликатов):** сразу при открытии страницы галереи (`/g/*`) или читалки (`/s/*`) расширение проверяет выбранную базовую папку (и реестр скачанных `GID`). Если манга уже лежит в папке (или собран её `.CBZ` / `.ZIP`), загорается зелёный бейдж **`✅ Уже в папке`**, а кнопка меняется на **`✅ Уже скачано`** и не качает мангу второй раз (если нужно принудительно перекачать поверх — `Shift + клик` по кнопке «Скачать»).

* **Кнопка «📂 Открыть папку» открывает именно папку манги:** при обычном клике открывается нативное окно Проводника прямо внутри созданной подпапки текущей манги (или вашей выбранной базовой папки для манги), а не системная папка «Загрузки».

* **Защита от `Extension context invalidated`:** при перезагрузке или обновлении расширения в `chrome://extensions` фоновый воркер автоматически переподключает `content.js` во всех открытых вкладках галерей и читалки, заменяя устаревшую панель без необходимости жать `F5`.

* **Умная докачка в папку (Smart Resume):** если в папке лежит только часть страниц (например, `18 из 45`), панель сразу показывает **`⚠️ В папке: 18/45 стр.`** и кнопку **`▶ Докачать (27 стр.)`**, мгновенно пропуская уже скачанные файлы без лишних запросов к `api.php`.

* **Спасение частичного `.CBZ` / `.ZIP` при отмене или обрыве:** если загрузка оборвалась на середине или была остановлена кнопкой «Отмена», уже скачанные страницы не пропадают из памяти, а автоматически пакуются в `Название_partial_p1-XX.cbz`.

* **Генерация `ComicInfo.xml`:** автоматическая сборка метаданных галереи (название, японский заголовок `#gj`, авторы, группы, пародии, персонажи, язык и теги `#taglist`) для читалок комиксов и пайплайнов перевода.

* **Умный фоллбэк `Оригинал (fullimg)` → `Сжатый (ридер)`:** если при скачивании оригиналов закончился лимит GP или сервер вернул ошибку 509, расширение не тратит холостые попытки `nl`, а автоматически сохраняет сжатую копию страницы.

## Сравнение режимов сохранения

| Режим | Куда сохраняются файлы | Особенности | 
| ----- | ----- | ----- | 
| **В папку `<Название манги>`** | `<Выбранная базовая папка>/<Название манги>/001_...` | Прямая запись на диск через `File System Access API` с защитой от дубликатов, докачкой (`Smart Resume`) и `ComicInfo.xml` | 
| **Единый `.CBZ` архив** | `<Выбранная базовая папка>/<Название манги>.cbz` (или `Загрузки`) | Готовый архив со встроенным `ComicInfo.xml` и автосохранением частичного архива при сбое | 
| **Единый `.ZIP` архив** | `<Выбранная базовая папка>/<Название манги>.zip` (или `Загрузки`) | Стандартный архив без повторного пережатия изображений (метод `STORE`) | 

## Установка

1. Скачайте релизный архив `exmanga_harvester_v1.9.zip` и распакуйте его в постоянную папку на компьютере.

2. Откройте в браузере страницу управления расширениями: `chrome://extensions`.

3. Включите переключатель **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.

4. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку с файлом `manifest.json`.

## Структура проекта

| Файл | Назначение | 
| ----- | ----- | 
| `manifest.json` | Конфигурация расширения Chrome Manifest V3 (`v1.9.0`) | 
| `content.js` | Парсер метаданных и тегов, детектор уже скачанной манги, клиент `api.php` с адаптивным таймингом и джиттером, упаковщик `PKZIP`, генератор `ComicInfo.xml`, `Smart Resume` и UI-панель | 
| `background.js` | Фоновый Service Worker для кросс-доменной загрузки байтов изображений, авто-переинжекта скриптов и хранения `lastHarvesterDownloadId` в `chrome.storage.session` | 
| `popup.html` / `popup.js` | Всплывающее окно настроек шаблонов, таймингов, докачки и дистанционного управления загрузкой | 
| `styles.css` | Стили встроенной тёмной панели управления на страницах галереи и читалки |
