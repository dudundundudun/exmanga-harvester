# ExManga Harvester Studio (Manifest V3)

Расширение для браузеров на базе Chromium (Google Chrome, Brave, Edge, Vivaldi, Яндекс.Браузер) для автоматического пакетного скачивания манги и галерей с **ExHentai** (`exhentai.org`) и **E-Hentai** (`e-hentai.org`) напрямую в одноимённую папку на диске или в готовый архив `.CBZ` / `.ZIP`.

> **Краткое описание для поля About на GitHub:**
> `Manifest V3 Chrome extension for batch downloading galleries from ExHentai & E-Hentai into named folders (via File System Access API without "Save As" popups) or single .CBZ / .ZIP archives with automatic H@H mirror fallback.`

## Ключевые возможности

* **Прямое сохранение в папку с названием манги без 500 окон «Сохранить как»:** использует `File System Access API` (`window.showDirectoryPicker` + `IndexedDB`) для прямой потоковой записи файлов на диск в обход `chrome.downloads`. Даже если в настройках браузера включён запрос пути для каждого файла, расширение спрашивает базовую директорию только один раз, автоматически создаёт внутри неё подпапку с именем манги и тихо сохраняет туда все страницы.
* **Упаковка в `.CBZ` и `.ZIP` на лету:** встроенный легковесный упаковщик `PKZIP` (`STORE` + `CRC32` + `UTF-8` без сторонних библиотек) собирает все выбранные страницы в единый архив для читалок комиксов или локальных переводчиков (например, `sloppy-manga-translator`).
* **Автоматический обход сбоев узлов Hentai@Home (`nl`):** при ошибке, таймауте или пустом ответе CDN-ноды расширение автоматически запрашивает резервное зеркало через токен `nl(...)` и продолжает загрузку без пропусков страниц.
* **Поддержка двух режимов качества:** позволяет скачивать как быстрые сжатые изображения из веб-ридера (`WebP` / `JPG` / `PNG`), так и полноразмерные оригиналы (`fullimg` / `fullimg.php` из блоков `#i6` и `#i7`).
* **Удобное управление со страницы и из Popup-меню:** встраивает панель управления прямо над сеткой превью галереи (`/g/*`) или над страницей читалки (`/s/*`), синхронизируя прогресс, паузу, отмену и кнопку быстрого открытия папки **«📂 Открыть папку»**.

## Сравнение режимов сохранения

| Режим | Куда сохраняются файлы | Особенности |
| :--- | :--- | :--- |
| **В папку `<Название манги>`** | `<Выбранная базовая папка>/<Название манги>/001_...` | Прямая запись на диск без засорения истории загрузок Chrome (`Ctrl+J`) и без всплывающих окон Проводника на каждую страницу |
| **Единый `.CBZ` архив** | `Загрузки/<Название манги>.cbz` | Готовый архив для комикс-ридеров (YACReader, CDisplayEx, Kavita) и пайплайнов перевода |
| **Единый `.ZIP` архив** | `Загрузки/<Название манги>.zip` | Стандартный архив без повторного пережатия изображений (метод `STORE`) |

## Установка

1. Скачайте релизный архив `exmanga_harvester_v1.8.zip` и распакуйте его в постоянную папку на компьютере.
2. Откройте в браузере страницу управления расширениями: `chrome://extensions`.
3. Включите переключатель **«Режим разработчика»** (*Developer mode*) в правом верхнем углу.
4. Нажмите кнопку **«Загрузить распакованное расширение»** (*Load unpacked*) и выберите папку с файлом `manifest.json`.

## Использование

1. Откройте любую страницу галереи (`/g/{gid}/{token}/`) или страницу чтения (`/s/{imgkey}/{gid}-{page}`) на `exhentai.org` или `e-hentai.org`.
2. На встроенной панели **ExManga Harvester** (или в иконке расширения на панели браузера) укажите диапазон страниц (по умолчанию с `1` до последней), формат сохранения и качество (`Сжатый (ридер)` или `Оригинал (fullimg)`).
3. При первом запуске в режиме **«В папку `<Название манги>`»** нажмите **«📁 Выбрать базовую папку»** (или **«Скачать»**) и укажите общую папку для манги — расширение запомнит её в `IndexedDB` для всех следующих загрузок и автоматически создаст внутри неё подпапку с именем текущей галереи.
4. После завершения скачивания нажмите **«📂 Открыть папку»**, чтобы открыть папку с загруженной мангой в Проводнике Windows (удерживайте `Shift` при клике, чтобы открыть диалог прямо внутри созданной подпапки манги на любом диске).

## Настройки (Popup-меню)

* **Диапазон страниц:** выбор начальной и конечной страницы для частичной докачки глав.
* **Имя подпапки:** шаблон именования создаваемой директории (`{title}`, `[{gid}] {title}` или `Manga/{title}`).
* **Шаблон имени файла:** сохранение с оригинальным именем (`001_Box_Back.webp`) или только по сквозному номеру с лидирующими нулями (`001.webp`).
* **Пауза между страницами (мс):** задержка между запросами к внутреннему `api.php` (`method: "showpage"`), по умолчанию `1200 мс` для соблюдения серверного кулдауна.
* **Повторы зеркала (`nl`):** максимальное число переключений резервного узла H@H при сбое загрузки страницы (по умолчанию `3`).

## Структура проекта

| Файл | Назначение |
| :--- | :--- |
| `manifest.json` | Конфигурация расширения Chrome Manifest V3, права доступа и правила инжекта |
| `content.js` | Парсер метаданных галереи/ридера, клиент `api.php`, упаковщик `PKZIP`, работа с `File System Access API` (`IndexedDB`) и UI-панель |
| `background.js` | Фоновый Service Worker для кросс-доменной загрузки байтов изображений в обход CORS и работы с `chrome.downloads` |
| `popup.html` / `popup.js` | Всплывающее окно настроек шаблонов, таймингов и дистанционного управления загрузкой |
| `styles.css` | Стили встроенной тёмной панели управления на страницах галереи и читалки |
